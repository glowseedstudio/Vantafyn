Vantafyn Companion

Server-side companion features and enhancements for Vantafyn clients.

Profile & Settings Sync

Synchronizes custom app settings, themes, home screen layouts, and watch preferences across all Vantafyn client devices.

Personal Playlists

Enables private, per-user personal playlists stored independently on the server and only visible to the user who created them.

Watch Parties

Enables synchronized group watch sessions, realtime member presence, play/pause synchronization, and in-app party invites.

Requests (Ombi)

Connects your Ombi server so Vantafyn users can search, request movies and series, and track approval status directly from inside the app.
Base URL of your Ombi instance, including http/https and port if applicable.
Found in Ombi Settings -> Ombi -> API Key.
Request timeout duration (2 to 30 seconds).
If unchecked, requests are processed using the server-wide master API key.

Companion Diagnostics

Server diagnostic snapshot and registered UnifiedPush client status.
