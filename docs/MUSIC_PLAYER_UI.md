# Music Player UI

Vantafyn Music now uses a premium mobile player surface built around:

- large centered album art;
- album-reactive colour background;
- marquee title and artist text;
- vivid cyan/blue/violet/magenta progress accents;
- flat secondary icon controls;
- a gradient primary play/pause button;
- structured queue cards with artwork.

The mini-player sits above the bottom rail and includes artwork, title, artist, previous, play/pause, next, and a thin gradient progress strip.

The full Now Playing screen exposes:

- Queue;
- More;
- Close;
- Shuffle;
- Previous;
- Play/Pause;
- Next;
- Repeat;
- New Playlist;
- Add to Playlist;
- Lyrics.

The More sheet shows only actions that are wired or safely available.
