# Music Test Matrix

## Now Playing

- Opens from mini-player.
- Album artwork is large and centered.
- Background stays readable.
- Progress can seek.
- Shuffle/repeat selected states are visible.
- Queue and More buttons open useful sheets.

## Mini-Player

- Shows artwork, title, artist, previous, play/pause, next.
- Progress strip updates.
- Long text marquee does not resize the row.
- Tapping opens full Now Playing.

## Queue

- Shows current and next items with artwork.
- Current track is highlighted.
- Tapping a row plays that queue item.
- Queue sheet does not sit under the bottom rail.

## Lyrics

- Lyrics screen opens from Now Playing.
- Synced lyrics highlight by playback position.
- Plain lyrics show cleanly.
- Missing lyrics show a polished empty state.

## Reliability

- Background playback continues.
- Lock-screen playback advances.
- Notification controls work.
- Video playback stops music.
- Logout/profile switch stops music.
- `:app-tv:assembleDebug` and `:app-mobile:assembleDebug` pass.
