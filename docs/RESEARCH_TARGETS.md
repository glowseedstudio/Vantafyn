# Research Targets

These projects and topics should be studied for product behavior, integration details, and architecture ideas. Do not copy GPL source into Vantafyn unless explicitly instructed and license implications are accepted.

## Android Clients

- Wholphin: Jellyfin Android TV connection flow, TV navigation, customizable home rows, playback engine choices, device profile handling, and library browsing patterns.
- Jellyfin Android TV: official Android TV behavior, playback profile decisions, Live TV support, and mature Jellyfin session edge cases.
- Findroid: modern Android Jellyfin client architecture, offline-friendly data handling, Compose UI, and mobile browsing flows.
- Finamp: Jellyfin authentication/session management, audio playback, downloads, and mobile media ergonomics.
- Pelagica: Jellyfin-adjacent UI and client patterns worth comparing for navigation and media presentation.

## Jellyfin Server And Plugin Concepts

- Home Screen Sections: how Jellyfin presents configurable home rows and what should be mirrored or improved client-side.
- Collection Sections: how collections are represented and how they should appear in TV and phone navigation.
- File Transformation: how transcoding, stream selection, subtitles, and container decisions affect client playback.
- SmartLists: playlist and dynamic list ideas that may influence future discovery rows.
- Jellyfin plugin template: plugin project structure and extension points, useful for understanding server-side customization opportunities.
